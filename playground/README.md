# Tanglaw FE-05 accessibility playground

Run `npm run dev:playground` and open the displayed local URL followed by `/playground/`. This independent Vite entry contains manual React and TypeScript implementations only; it deliberately does not import shadcn/ui, Radix UI, or another component library.

Keyboard checks: Tab to the dialog trigger and activate it with Enter or Space. Tab and Shift+Tab cycle in the dialog, Escape closes it, and focus returns to the trigger. In the tabs, use Left/Right Arrow, Home, and End. For the disclosure, use Tab then Enter or Space.
