Each role should be presented as an interactive card or selectable option with:

* Role title
* Short description
* Icon
* Brief explanation of responsibilities

After selecting a role, simulate role-based navigation on the frontend only (no backend logic required).

Each role should have its own dedicated dashboard layout and only display the features relevant to that user according to my paper.

Examples of frontend behavior:

* Show/hide navigation items based on the selected role.
* Display role-specific quick actions.
* Restrict access to unauthorized pages with frontend guards.
* Include placeholder pages for features not yet implemented.

Design each dashboard to feel tailored to its role while maintaining the same design system and visual identity.
