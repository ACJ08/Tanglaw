# Prompt

Act as a **Senior Frontend Engineer, Senior UI/UX Designer, Visual Designer, Design Systems Architect, Color Theory Specialist, Accessibility Expert (WCAG AA/AAA), Human-Computer Interaction (HCI) Specialist, and CSS/Tailwind Expert** with over **15 years of experience** designing enterprise SaaS platforms, AI-powered applications, civic technology platforms, and award-winning web interfaces.

Your task is to **perform a comprehensive visual audit of the entire Tanglaw P2P frontend**, focusing specifically on the **background colors, overlays, cards, pop-ups, modals, dialogs, panels, widgets, containers, and reusable UI components** across every page and every feature.

Do **not** simply replace the existing Navy Blue backgrounds with another color. Instead, analyze the overall design system, typography, visual hierarchy, accessibility, and contrast to determine where background colors should be adjusted to improve readability and create a more balanced Light Mode experience.

---

# Objective

One of the major visual issues is that several components still use **very dark Navy Blue backgrounds**, particularly in:

* Pop-up dialogs
* Modal windows
* Floating cards
* Dashboard widgets
* AI assistant panels
* Notification panels
* Information boxes
* Hero decorative elements
* Dashboard sections
* Verification result cards
* Community cards
* Analytics cards
* Tooltips
* Side panels
* Expandable cards
* Interactive containers
* Status panels
* Overlay components

The current Navy Blue is too dark for Light Mode, creating excessive contrast with the surrounding interface and making the design feel visually heavy.

---

# Required Design Direction

Instead of using a deep Navy Blue background, redesign these components using a **lighter, softer blue palette** that is specifically optimized for Light Mode.

The new background should feel:

* Softer
* Brighter
* More modern
* More spacious
* Less visually heavy
* More harmonious with the warm Light Mode theme
* Easier on the eyes
* More consistent with the rest of the interface

The lighter blue should preserve Tanglaw's branding while reducing unnecessary visual weight.

---

# Color Palette Guidance

Maintain Navy Blue as the **primary brand color**, but reserve the darkest shades for:

* Primary buttons
* Navigation highlights
* Active states
* Important icons
* Key headings
* Critical actions

For backgrounds and large surfaces, transition to lighter tones such as:

* Soft Navy
* Light Slate Blue
* Powder Blue
* Sky Blue
* Pale Azure
* Mist Blue
* Cool Blue-Gray
* Very Light Navy Tint

Avoid backgrounds that are so dark they compete with the text or dominate the page.

---

# Improve Text Readability

One of the primary goals is to improve typography.

Many components currently have:

* Dark backgrounds
* Dark text
* Heavy visual contrast
* Inconsistent readability

Adjust the background colors so that darker typography becomes easier to read.

The relationship between background and typography should feel balanced.

For example:

Instead of:

Dark Navy background

*

Dark Navy text

Create:

Light Blue background

*

Dark Navy typography

This creates:

* Better readability
* Better accessibility
* Better visual hierarchy
* Less eye strain
* Cleaner presentation

# Preserve Contrast

Do not simply brighten every component.

Instead, evaluate each one individually.

Maintain strong visual hierarchy by balancing:

* Background color
* Typography
* Icons
* Borders
* Shadows
* Buttons
* Hover states

The interface should retain depth without relying on overly dark backgrounds.

---

# Create Layered Surfaces

Rather than using one solid Navy Blue everywhere, introduce layered surfaces such as:

* Soft blue backgrounds
* White cards
* Warm cream sections
* Light blue containers
* Subtle borders
* Soft shadows
* Gentle gradients

This creates a more modern, premium, and spacious interface.

---

# Accessibility Requirements

All redesigned backgrounds must meet WCAG AA (preferably AAA) accessibility standards.

Ensure:

* Excellent contrast between text and background.
* No dark text placed on dark blue backgrounds.
* No low-contrast combinations.
* Clear distinction between interactive and non-interactive elements.
* Readable typography across all components.

---

# Design Philosophy

The Light Mode should feel bright, welcoming, and trustworthy while preserving Tanglaw's identity. Replace visually heavy Navy Blue backgrounds with lighter blue tones that create a cleaner, more approachable interface. The darker Navy Blue should remain a branding accent for headings, navigation, and primary actions, while larger background surfaces should use softer blue shades to improve readability, reduce eye strain, and create a cohesive visual hierarchy.

Every page, modal, pop-up, card, and reusable component should feel balanced, polished, and professionally designed, with typography remaining highly readable and the interface maintaining a consistent, modern, production-ready Light Mode aesthetic.
